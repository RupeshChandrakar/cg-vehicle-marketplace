# Admin / Agent Web

Internal console for admins and agents — vehicle approval, enquiry workflow, agent management. Next.js (App Router) + TypeScript.

Runs on **http://localhost:3001**. See the [repo root README](../../README.md) for full setup instructions.

## Scripts

- `pnpm dev` — start the dev server
- `pnpm build` — production build
- `pnpm lint` / `pnpm typecheck` — code quality checks
