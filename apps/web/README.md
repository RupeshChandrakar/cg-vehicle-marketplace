# Customer Web

Public-facing marketplace site — browse, search, and enquire about vehicles. Next.js (App Router) + TypeScript.

Runs on **http://localhost:3000**. See the [repo root README](../../README.md) for full setup instructions.

## Scripts

- `pnpm dev` — start the dev server
- `pnpm build` — production build
- `pnpm lint` / `pnpm typecheck` — code quality checks
